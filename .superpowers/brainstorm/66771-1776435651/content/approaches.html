Como resolver o fundo branco?

Tens duas abordagens principais — cada uma tem trade-offs diferentes

🔦
CSS only

A — CSS mix-blend-mode: multiply (sem editar o vídeo)

O fundo branco desaparece automaticamente em backgrounds escuros. Zero edição de vídeo. Pode ter limitações se o personagem tiver partes muito claras.

Prós

  • Não precisas de editar o vídeo
  • Rápido de implementar

Contras

  • Partes claras do personagem ficam semitransparentes
🔦
WebM + alpha

B — Exportar como WebM com fundo transparente

Usas o DaVinci Resolve (grátis) ou After Effects para remover o fundo branco e exportar como WebM com canal alpha. Resultado perfeito.

Prós

  • Resultado perfeito, sem artefactos
  • Controlo total do CSS

Contras

  • Precisas de editar o vídeo
  • Ficheiro WebM maior

💡 Recomendação: começa com A (CSS) para ver o resultado — se ficar bem, não precisas de editar o vídeo
